## Overview

Codesense is a SAAS product developed to assist open source contributors , new developers and anyone interested to efficiently contribute to a codebase . 

## Features

1. Easy to understand codebase summary
2. Helpful chatbot with the ability to answer questions regarding the codebase
3. Easy to use interface
4. Easy setup and history tracking of conversations.
5. Explain this file feature

## Tech stack

Client application: React JS , Tailwind CSS , Ant Design
Server application: FastAPI ,
Database: MongoDB , MongoDB vector store
Containerization and deployment: Docker , render
